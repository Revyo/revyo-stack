# Revyo Engineering

All current skills from [Matt Pocock](https://github.com/mattpocock/skills) and
[Poteto's pstack](https://github.com/cursor/plugins/tree/main/pstack), including
the Benny automation skills. Upstream additions in the selected source trees are
picked up by the weekly updater.

Every skill has a concise discovery entry point, automatic invocation enabled,
upstream guidance and resources, source provenance, and its original license.
Matt's colliding names are installed as `matt-prototype`, `matt-tdd`, and
`matt-teach`; Poteto keeps `tdd` and `teach`, and Emil keeps `prototype`.

The [engineering router](../skills/revyo-engineering/SKILL.md) selects relevant
workflows without requiring a named invocation. Cursor-specific agent names,
model choices, and tool calls are adapted to the available environment. Optional
panels and setup do not prevent direct work or authorize unrelated external actions.

Maintain selections in [upstream-sources.json](../upstream-sources.json) and
local discovery overrides in [upstream-overrides.json](../upstream-overrides.json).
Upstream files are generated snapshots; do not edit them by hand.
